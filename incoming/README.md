# Сюда кладутся нарисованные спрайты

Папка для исходников от художника. Кладёшь файл — говоришь мне, я разбираю: проверяю
размер и альфу, привязываю цвета к палитре, ставлю в `public/assets/`, обновляю реестр
и страницу приёмки.

**Исходники остаются здесь навсегда.** В `public/assets/` уезжает обработанная копия,
а мастер-файл нужен, если понадобится пересобрать: привязка к палитре необратима.

## Как загрузить

**Через GitHub** — открыть эту папку на github.com, `Add file → Upload files`. Так уже
приезжали компас и часы, способ рабочий.

**Через scp**, если удобнее из терминала:

```
scp compass.png fishruff@142.93.4.89:~/hui/expedition_web/incoming/
```

## Как называть

Именем будущего ассета: `compass.png`, `lamp.png`, `chest.png`. Список имён — в таблицах
[`../docs/art/README.md`](../docs/art/README.md). Если приложил несколько попыток одного
предмета, добавляй номер: `lamp-2.png`, и скажи, какая нравится больше.

## Что проверяю при приёмке

| Что | Как должно быть | Что будет, если не так |
| --- | --- | --- |
| Альфа | только 0 и 255 | полупрозрачные края дают на сайте грязную кайму |
| Сетка | один к одному, без апскейла | картинка мылится при увеличении браузером |
| Размер | из таблицы канона | предмет выбьется из общей плотности |
| Палитра | цвета из `docs/art/expedition.gpl` | предмет будет выглядеть из другой игры |

Первые два — на тебе, их не починить постобработкой. Палитру и лишние цвета привожу я:
у компаса и часов это заняло секунду и картинки не изменило.
