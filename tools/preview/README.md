# Служебные страницы приёмки

Сюда смотрят, когда от художника приходит новый файл. Частью сайта они не являются
и в сборку не попадают.

Открываются на живом дев-сервере — путь от корня репозитория, а не от корня сайта:

```
http://localhost:5173/tools/preview/assets-preview.html
http://localhost:5173/tools/preview/compare-watch.html
```

Раньше они лежали в `public/`, и Vite копировал их в `dist/` как есть: после деплоя
внутренняя страница приёмки открывалась бы по адресу сайта. Всё, что лежит в `public/`,
уезжает к посетителю — это и есть смысл папки.

Ссылки на `/assets/...` внутри страниц остались абсолютными: на дев-сервере они ведут
в ту же `public/`, что и на сайте.
