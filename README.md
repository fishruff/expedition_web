# Expedition — сайт Minecraft-сервера

Сайт сервера **Expedition** в пиксельном оформлении: стол, дневник экспедиции, экипаж, летопись
находок и устав.

## Стек

| Что | Чем |
| --- | --- |
| Сборка | Vite 8 (Rolldown) |
| UI | React 19 + React Compiler |
| Язык | TypeScript |
| Стили | SCSS-модули (`sass-embedded`) |
| Роутинг | React Router 8 |
| Тесты | Vitest + Testing Library |
| Линтер | ESLint 10 (flat config) |

## Запуск

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm run build    # типы + продакшн-сборка в dist/
npm run preview  # локальный просмотр собранного
npm test         # vitest
npm run lint     # ESLint
```

Нужен Node.js 22.22+ (требование jsdom в тестах; сама сборка живёт и на 20.19+).


## Правила пиксельного оформления

Их нарушение сразу видно на экране — картинка начинает мылить.

- **Масштаб только целый.** Живёт в CSS-переменной `--s`, считается в `src/scene/useScale.ts`.
  Размеры задаются через функцию `px(n)` из миксинов, а не в пикселях напрямую.
- **Ассеты хранятся в родном размере** — маленькими. Браузер увеличивает их целым числом раз.
  Большой файл не улучшает картинку, а ухудшает: при дробном увеличении точки расплываются.
- **Только PNG.** JPEG размазывает пиксельные края.
- **Три типа ассетов**, каждый со своим поведением при адаптиве:
  - *тайл* — повторяется и заполняет любой размер (дерево, бумага), миксин `tile()`;
  - *рамка из девяти слоёв* — тянется под содержимое, углы целы (панели, книга), миксин `nine-slice()`;
  - *предмет* — не тянется никогда, только целый масштаб (компас, часы, арт игрока).
- **Никаких размытий и скруглений.** Ни `border-radius`, ни размытых теней.
- **Анимации ступенчатые** (`steps()`), плавность выдаёт непиксельность.
- Контент правится в `src/content/*.json`, разметку для этого трогать не нужно.
